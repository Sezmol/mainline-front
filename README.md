# mainline - клиентская часть

Социальная сеть для инженеров. В ленте четыре вида записей - обычная запись, вакансия,
событие и задача. Есть профили с работами, компании с отделами и командами, проекты
с доской задач, отклики и приглашения, уведомления и чаты, где сообщения приходят
без перезагрузки страницы.

Здесь веб-приложение. Серверная часть в `mainline-back`.

## Стек

| Что                | Чем                                                 |
| ------------------ | --------------------------------------------------- |
| Язык               | TypeScript 6                                        |
| Каркас             | React 19 с compiler                                 |
| Сборка             | Vite 8                                              |
| Маршруты и запросы | TanStack Router и TanStack Query                    |
| Состояние          | Zustand                                             |
| Оформление         | Tailwind 4, элементы интерфейса на Base UI (shadcn) |
| Формы              | react-hook-form и zod 4                             |
| Сообщения          | socket.io-client                                    |
| Разметка текста    | react-markdown, подсветка кода через shiki          |
| Даты               | dayjs                                               |
| Перетаскивание     | dnd-kit                                             |
| Значки             | Phosphor                                            |
| Архитектура        | Feature-Sliced Design, проверяется steiger          |
| Обращения к API    | создаются из описания OpenAPI сервера               |
| Пакеты             | pnpm, Node 24                                       |

## Запуск

Для запуска требуется Node 24 и pnpm. Переменных окружения нет.

```bash
pnpm install
pnpm dev
```

Приложение открывается на `http://localhost:5173`, запросы к `/api` уходят на
`http://localhost:3000`, поэтому рядом должен быть запущен `mainline-back`.

## Каталоги

```
src/
  app/         точка входа, маршруты, оболочка страницы, панель чатов
  pages/       страницы - лента, запись, профиль, компания, команда, проект, доска
  features/    действия - формы, лайки, отклики, приглашения, перенос задач
  entities/    сущности - запись, пользователь, компания, отдел, команда, чат, проект
  shared/      общее - обращения к API, элементы интерфейса, вспомогательные функции
```

Код в `src/shared/api/generated` создан по описанию OpenAPI и хранится в репозитории,
чтобы приложение собиралось без запущенного сервера. Обновить - `pnpm api:generate`
при запущенном `mainline-back`.
